<task type="auto">
  <name>Task 2: Create nextest configuration</name>
  <files>.config/nextest.toml</files>
  <action>
Create cargo-nextest configuration file:

1. **Create .config directory** if it doesn't exist

2. **Create .config/nextest.toml** with profiles for local and CI:
   ```toml
   # nextest configuration
   # Docs: https://nexte.st/docs/configuration/

   [profile.default]
   # Local development profile - fast feedback
   retries = 0
   test-threads = "num-cpus"
   fail-fast = true
   slow-timeout = { period = "60s" }

   [profile.ci]
   # CI profile - thorough testing with retries
   retries = 2
   test-threads = "num-cpus"
   fail-fast = false
   slow-timeout = { period = "120s", terminate-after = 3 }

   # JUnit XML output for CI test reporting
   [profile.ci.junit]
   path = "target/nextest/junit.xml"

   # Override for integration tests (if any) - may need more time
   [[profile.default.overrides]]
   filter = 'test(integration_)'
   retries = 1
   slow-timeout = { period = "120s" }
   ```

This configuration:
- default: Fast local development (fail-fast, no retries)
- ci: Thorough CI runs (retries, JUnit output, no fail-fast)
- Slow test timeout warnings
- Integration test overrides
